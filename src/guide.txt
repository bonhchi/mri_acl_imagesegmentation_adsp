HƯỚNG DẪN LÀM VIỆC (TIẾNG VIỆT)

1. Chuẩn bị môi trường
----------------------
- Mở PowerShell và di chuyển tới dự án:
    cd /d D:\Master\ImageSegmentation\Demo
- Tạo virtualenv:
    python -m venv .venv
    .\.venv\Scripts\activate
- Cập nhật tooling và cài đặt phụ thuộc:
    python -m pip install --upgrade pip setuptools wheel
    pip install -r requirements.txt
- Nếu thiếu dotenv:
    pip install python-dotenv
- Kiểm tra nhanh phiên bản:
    python - <<'PY'
    import torch, monai
    print("Torch:", torch.__version__, "CUDA:", torch.cuda.is_available())
    if torch.cuda.is_available():
        print("GPU:", torch.cuda.get_device_name(0))
    print("MONAI:", monai.__version__)
    PY

2. Cấu trúc chính
-----------------
| Thư mục | Vai trò |
| artifacts/ | Kết quả preprocess (volume.npz, tensor.pt, preview, preview_mask) |
| dataset/   | Dữ liệu thô fastMRI (.h5), KneeMRI (.pck), OAI-ZIB (.npz) |
| lists/     | train.txt + val.txt cho các lần training |
| runs/      | Lưu checkpoint (`best.pt`), lịch sử, ảnh mẫu |
| src/       | Mã nguồn adapters, preprocess, training |
| src/.env   | (nếu có) Khai báo FASTMRI_ROOT, KNEE_MRI_ROOT, OAI_ZIB_ROOT |

3. Tiền xử lý dữ liệu
---------------------
3.1 fastMRI (HDF5)
    python src/train_unet_launcher.py ^
      --dataset fastmri ^
      --dataset-root dataset/singlecoil_train ^
      --artifact-dir artifacts/fastmri_knee ^
      --preview-max 6

3.2 KneeMRI (pickle volume + ROI)
    python src/train_unet_launcher.py ^
      --dataset kneemri ^
      --dataset-root dataset/kneemri ^
      --artifact-dir artifacts/kneemri_acl ^
      --slice-keep 0.0,1.0 ^
      --preview-max 6

3.3 OAI-ZIB (npz + csv mapping)
    python src/train_unet_launcher.py ^
      --dataset oaizib ^
      --dataset-root dataset/OAI-ZIB-framelast ^
      --artifact-dir artifacts/artifacts/oaizib_knee ^
      --skip-split ^
      --skip-train

Ghi chú:
- Các lần chạy sau có thể thêm `--skip-preprocess` để bỏ qua bước xử lý nếu volume.npz đã tồn tại.
- Khi kết hợp nhiều bộ (fastmri + kneemri + oaizib), dùng `--dataset combine` ở bước train (không cần preprocess).
- Preview PNG được lưu ở `preview/` (ảnh intensity) và `preview_mask/` (mask nhị phân) để QA nhanh.

4. Tạo danh sách train/val
--------------------------
Tự động bằng launcher:
    python src/train_unet_launcher.py --dataset ... --skip-preprocess --skip-train
Hoặc thủ công:
    for /r artifacts\fastmri_knee %f in (volume.npz) do @echo %f>>lists\all.txt
    python - <<'PY'
    import random, pathlib
    L = [ln.strip() for ln in pathlib.Path("lists/all.txt").read_text().splitlines() if ln.strip()]
    random.seed(42); random.shuffle(L)
    k = int(len(L) * 0.8)
    pathlib.Path("lists/train.txt").write_text("\n".join(L[:k]), encoding="utf-8")
    pathlib.Path("lists/val.txt").write_text("\n".join(L[k:]), encoding="utf-8")
    PY

5. Huấn luyện UNet 2D / 2.5D
----------------------------
Chạy end-to-end (preprocess + split + train):
    python src/train_unet_launcher.py ^
      --dataset fastmri ^
      --dataset-root dataset/singlecoil_train ^
      --artifact-dir artifacts/fastmri_knee ^
      --out-dir runs/fastmri_unet ^
      --epochs 80 ^
      --batch-size 8 ^
      --workers 4 ^
      --amp

Huấn luyện OAI-ZIB với danh sách đã chuẩn bị (khuyến nghị hiện tại):
    python src/train_unet_launcher.py ^
      --dataset oaizib ^
      --artifact-dir artifacts/artifacts/oaizib_knee ^
      --train-list lists/oaizib_knee/train.txt ^
      --val-list lists/oaizib_knee/val.txt ^
      --skip-preprocess ^
      --skip-split ^
      --out-dir runs/oaizib_unet ^
      --epochs 80 ^
      --batch-size 64 ^
      --workers 8 ^
      --run-tag oaizib ^
      --prefetch-gpu ^
      --prefetch-factor 4 ^
      --persistent-workers ^
      --cache-mode cpu ^
      --amp

Ghi chú:
- `--skip-preprocess` và `--skip-split` dùng khi `volume.npz` cùng danh sách train/val đã tạo ở bước 3 và 4.
- `--cache-mode cpu` phù hợp khi artifact nằm trên HDD, cần sẵn RAM trống; có thể chuyển sang `mmap` hoặc `gpu` tùy cấu hình.
- `--prefetch-gpu` giúp giảm độ trễ nạp batch khi VRAM còn đủ; kết hợp `--prefetch-factor 4` và `--persistent-workers` giảm thời gian chờ giữa các epoch.

Ghi chú: list/train.txt, list/val.txt nên ở dạng dataset|D:\...\volume.npz để chạy chung nhiều bộ dữ liệu.
Mẹo GPU: thêm --prefetch-gpu sẽ đẩy batch lên VRAM, giảm tải RAM khi train 2D/2.5D.

Các tùy chọn hay dùng:
| Cờ | Ý nghĩa |
| --skip-preprocess | Bỏ qua tạo volume (đã có sẵn) |
| --skip-split      | Giữ nguyên train/val list hiện tại |
| --skip-train      | Chỉ chạy tới bước trước training |
| --model unetpp    | Chọn UNet++ |
| --encoder densenet121 | Đổi backbone |
| --prefetch-gpu     | Prefetch batch lên GPU, giảm copy từ RAM |
| --cache-mode cpu   | Cache toàn bộ volume trên RAM, giảm đọc đĩa |
| --auto-gpu        | Bật AMP + prefetch và tăng batch/worker tùy VRAM |
| --prefetch-factor | Điều chỉnh số batch được nạp sẵn mỗi worker (mặc định 2) |
| --persistent-workers | Giữ DataLoader workers chạy xuyên suốt, giảm thời gian restart |
| --run-tag exp1    | Gắn hậu tố vào thư mục run |

Tip: Nếu GPU còn trống ≥12GB VRAM, thêm `--auto-gpu` để launcher tự bật mixed precision, prefetch và nâng batch size/worker. Khi VRAM thấp hơn, cấu hình sẽ giữ nguyên để tránh OOM.
Nếu dữ liệu nằm trên HDD chậm, bật thêm `--cache-mode cpu` để giữ volume trong RAM (cần ít nhất vài GB RAM rảnh).

6. Huấn luyện UNet 3D
---------------------
Yêu cầu volume.npz cho từng dataset.
    python src/train/train_unet3d.py ^
      --train-list lists/fastmri_knee/train.txt ^
      --val-list lists/fastmri_knee/val.txt ^
      --out-dir runs/unet3d ^
      --patch-size 160 160 64 ^
      --patches-per-volume 12 ^
      --batch-size 2 ^
      --epochs 80 ^
      --cache-mode gpu ^
      --prefetch-gpu ^
      --amp

Chú ý: list/train.txt, list/val.txt nên ở dạng `dataset|D:\path\volume.npz`. Nếu thiếu nhãn, loader sẽ tự đoán theo thư mục (fastmri / kneemri / oaizib / combine).

Các tùy chọn chính:
| --pos-frac 0.5     | Tỷ lệ lấy patch dương |
| --eval-overlap 0.5 | Độ chồng khi validate |
| --channels ...     | Tùy chỉnh chiều UNet |
| --normalize none   | Bộ chuẩn hóa bổ sung |
| --cache-mode cpu   | Cache volume trên RAM, giảm áp lực GPU |
| --cache-mode mmap  | Dùng memmap giảm RAM, cần disk NVMe nhanh |
| --cache-mode none  | Tải lại từng patch, tiết kiệm RAM nhưng tốn CPU/disk |
| --auto-gpu         | Tự động nâng batch size/prefetch/cache theo VRAM |
| --prefetch-gpu     | Đẩy batch kế tiếp lên VRAM, giảm copy CPU->GPU |

Ghi chú hiệu năng:
- GPU: `--cache-mode gpu` giữ volume trên VRAM, training nhanh hơn nhưng tốn bộ nhớ GPU; script sẽ tự ép `workers=0`.
- RAM: Nếu RAM gần đầy hãy chuyển sang `--cache-mode cpu` hoặc `mmap`, cân nhắc bỏ `--prefetch-gpu`.
- CPU/disk: `--cache-mode none` phù hợp khi có NVMe nhanh, đổi lại CPU cao hơn.

Khi GPU còn trống ≥28GB VRAM, `--auto-gpu` sẽ tự chuyển `cache_mode=gpu`, tăng batch size và bật prefetch. Nếu VRAM ít hơn, cấu hình được giữ nguyên để tránh thiếu bộ nhớ.

7. Theo dõi và checkpoints
--------------------------
- Checkpoint tốt nhất: `runs/<dataset>_unet/<run_name>/best.pt`
- Các run đều lưu `history.csv`, `history.json`, ảnh mẫu trong `samples/`
- TensorBoard (nếu bật logger tensorboard):
    tensorboard --logdir runs/<dataset>_unet
- Thư mục `checkpoints/` bên trong mỗi run để dành cho checkpoint phụ (mặc định rỗng).

8. Inference nhanh
------------------
Ví dụ suy luận 2D:
    python src/infer.py ^
      --ckpt runs/fastmri_unet/2025-10-26_unet_resnet34/best.pt ^
      --volume artifacts/fastmri_knee/file1000001/volume.npz ^
      --out out/predict

9. Lưu ý cho kết hợp (combine)
------------------------------
- Cần chuẩn bị train.txt/val.txt liệt kê volume.npz từ nhiều bộ dữ liệu.
- Huấn luyện:
    python src/train_unet_launcher.py ^
      --dataset combine ^
      --artifact-dir artifacts/combine ^
      --train-list lists/train_combine.txt ^
      --val-list lists/val_combine.txt ^
      --skip-preprocess ^
      --skip-split ^
      --run-tag combine ^
      --epochs 80
- Thư mục run sẽ có hậu tố `_combine`.
